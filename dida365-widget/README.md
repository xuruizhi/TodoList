# 滴答清单桌面任务悬浮窗

从滴答清单（Dida365）同步**今天的任务**，按**标签分组**显示在桌面右上角的无边框悬浮窗中，无需打开任何界面。
支持：标记完成 / 撤销完成 / 改期（今天、明天、后天、自定义日期时间）/ 删除任务 / 在滴答清单中打开；**窗口置顶默认关闭**，可一键开启。

## 文件说明

| 文件 | 作用 |
|---|---|
| `DidaWidget.exe` | **推荐**：独立打包版，双击即用，不依赖任何 Python 环境 |
| `dida_widget.py` | 主程序源码（仅依赖 Python 标准库，无需安装任何第三方包） |
| `启动桌面任务.bat` | 双击即可用系统 Python 启动悬浮窗（无控制台窗口） |
| `config.json` | 首次运行后生成：保存 API 口令、窗口位置、刷新间隔 |
| `widget.log` | 运行日志，出问题时查看这里 |

## 快速开始（3 步）

1. **获取 API 口令**
   打开 https://www.dida365.com ，登录后点击左上角**头像** → **设置** → **账户与安全** → **API 口令** → 创建并复制。

2. **启动程序**
   双击 `DidaWidget.exe`（或 `启动桌面任务.bat`）。首次运行会自动弹出设置窗口，粘贴口令后点「保存并连接」。

3. **完成**
   悬浮窗出现在桌面右上角，自动同步今天的任务。

## 操作说明

- **点击任务行 / 复选框**：标记完成（完成的任务会移到下方「今日已完成」区，可点击撤销）
- **按标签分组**：任务按第一个标签分组显示，无标签的任务归入「无标签」组
- **时间标注（与网页版拉齐）**：今天的任务——定时显示时间（如 `16:00`）、全天显示「今天」；其他日期的任务直接标注日期（如 `9月23日`、`2025年6月30日`），不显示「逾期」
- **右键任务**：菜单 → 标记完成 / 改期（今天 / 明天 / 后天 / 自定义）/ 在滴答清单中打开 / 删除
- **改期自定义格式**：
  - `2026-10-01` → 全天
  - `2026-10-01 14:30` → 定时
  - `14:30` → 今天 14:30
  - `10-02 09:00` → 今年 10月2日 09:00
- **右键标题栏**：配置项带勾选标记——窗口置顶（✓ 置顶）/ 立即刷新 / 自动刷新间隔（单选，当前值打勾）/ 显示今日已完成（✓ 显示）/ 窗口自适应高度（✓ 按内容伸缩）/ 开机自启（✓ 已启用）· **设置**（API 口令 + 字体 / 字号 / 文字颜色 / 强调色）/ 退出
- **标题栏按钮**：📌 置顶（默认关闭，点亮即置顶）· ⟳ 刷新 · ✕ 退出（设置入口在右键标题栏 →「设置…」）
- **拖动标题栏**：移动悬浮窗位置（自动记住）
- **调整大小（可自由拖动）**：拖窗口**右侧边缘**调宽度、**底部边缘**调高度、**右下角手柄**同时调长宽，调整后自动记住；**双击右下角手柄**或右键标题栏 →「窗口自适应高度」可恢复按内容自动伸缩（**含今日已完成条目**，任务超出屏幕高度时才开始滚动）
- **定时自动刷新**：默认**每 5 分钟**自动同步一次（状态条会显示「每5分钟自动刷新」），刷新时保持当前滚动位置不跳顶；右键标题栏 →「自动刷新间隔」可改为 1 / 15 / 30 / 60 分钟或关闭

## 开机自启

右键标题栏 → 勾选「**开机自启**」即可加入 Windows 启动文件夹；取消勾选即移除。

## 常见问题

| 现象 | 处理 |
|---|---|
| 状态条提示「API 口令无效或过期」 | 右键标题栏 →「设置…」，粘贴新口令后保存并应用 |
| 提示「网络错误」 | 检查网络；程序会每 5 分钟自动重试，也可点 ⟳ 手动刷新 |
| 想调整位置 | 按住标题栏拖动，位置自动保存 |
| 想彻底退出 | 点 ✕ 或右键标题栏 → 退出（开机自启的会在下次开机再出现） |
| 出问题不知道原因 | 打开同目录 `widget.log` 查看日志 |

## 技术说明

- 使用滴答清单官方开放接口：`https://api.dida365.com/open/v1`（任务列表用 `POST /task/filter`，时间字段为 UTC），认证方式为官方 **API 口令**（Bearer Token）
- “今天的任务” = 今天到期 + 逾期未完成 + 今天已完成（与滴答清单「今天」智能清单口径一致）
- 程序仅使用 Python 标准库（tkinter + urllib），可离线使用；`config.json` 中明文保存口令，请勿分享该文件
- 要求 Python ≥ 3.10（本机已装 3.13）
